## 3. 录制中的常见故障

| 现象 | 处理 |
|---|---|
| `docker: not recognized` | 本终端在装 Docker 之前打开过 → 脚本会自动修 PATH；仍不行就重开一个终端再录 |
| `engine: not running` | 先开 Docker Desktop，等引擎就绪再录 |
| `relation "dw.v_..." does not exist` | 说明 DDL 之后没重建视图 → 重跑 `verify-e2e.ps1`（脚本已内含该顺序） |
| psql 中文注释乱码 | 只影响注释，不影响结果；可忽略（SQL 文件是 UTF-8） |
| 时间超 5 分钟 | 把 ③ 的等待过程**加速播放**（注明"speed up, no cut"），**不要删除任何步骤** |
