## 2. 演示 ETL 从零重建（第 3 部分）

```powershell
cd "32113\02_作业\A2\lab-env\advanced-database-lab"
$env:PATH += ';' + "$env:LOCALAPPDATA\Programs\DockerDesktop\resources\bin"
$p3 = 'workspace\part3_warehouse_etl'
foreach ($f in '01_source_ddl.sql','02_warehouse_ddl.sql','90_fixtures_sources.sql','02b_dimensions.sql','03_identity_xref.sql','04_etl_load_facts.sql') {
  Get-Content "$p3\$f" -Raw | docker compose exec -T postgres psql -v ON_ERROR_STOP=1 -U student -d lab
  "exit=$LASTEXITCODE  $f"
}
```
口播要点：三个源系统（S1 core banking / S2 payments / S3 digital & service）→ 维度 + 事实 + `customer_xref`；
每一步都打印真实退出码，任一失败即停（`ON_ERROR_STOP=1`）。

## 3. 演示对账与数据质量（第 3 部分）

```powershell
Get-Content "$p3\05_reconciliation.sql" -Raw | docker compose exec -T postgres psql -v ON_ERROR_STOP=1 -U student -d lab
```
重点展示：
- T1 计数对账 `7 - 1 = 6`（1 笔孤儿交易被**记录**而不是丢弃）
- T1b 金额对账 `1835.50 = 1835.50`
- T4 **ambiguous = 2**（P001/P004 共用邮箱 → 不自动合并）
- `rejected_record` 里能看到 `T0007 unknown account_id (orphan)`

## 4. 演示三条报表（第 5 部分）

```powershell
cd "32113\02_作业\A2\lab-env\advanced-database-lab"
# 4.1 先建报表视图（必须在仓库 DDL 之后：DROP TABLE … CASCADE 会把视图一起删掉）
Get-Content 'workspace\part5_reports_testing\10_report_views.sql' -Raw | docker compose exec -T postgres psql -v ON_ERROR_STOP=1 -U student -d lab
# 4.2 再跑三条报表
Get-Content 'workspace\part5_reports_testing\r1_r2_r3_reports.sql' -Raw | docker compose exec -T postgres psql -v ON_ERROR_STOP=1 -U student -d lab
```
口播要点：**先分别聚合各 fact 再 join**，否则金额/计数会被连接放大（脚本末尾留了反例注释可讲 trade-off）。
> 更省事的做法：直接跑 `命令\verify-e2e.ps1`（它已含建视图这一步，并自动跑两遍验证幂等）。

## 5. 演示幂等性（第 3 部分，A2 要求"可直接执行无错"）

把第 2 步**再跑一遍**，然后对比指纹：
```powershell
# 简化版：确认计数在第二次运行后不变
docker compose exec -T postgres psql -U student -d lab -c "SELECT (SELECT count(*) FROM dw.fact_transaction) tx, (SELECT count(*) FROM dw.customer_xref) xref, (SELECT sum(amount_aud) FROM dw.fact_transaction) amt;"
```
预期第二次仍是 `tx=6, xref=14, amt=1835.50`。

## 6. 演示边界/失败路径（最能拿分的部分）

```powershell
docker compose exec -T postgres psql -U student -d lab -c "SELECT * FROM dw.rejected_record;"
docker compose exec -T postgres psql -U student -d lab -c "SELECT source_system, source_customer_id, match_status FROM dw.customer_xref WHERE match_status <> 'matched' ORDER BY 1,2;"
```
口播要点：孤儿交易被拒并留证；未匹配/歧义身份保留可见，**不猜、不静默丢行**。
